# 미트웰 발주서 자동화

스마트스토어 + 카페24 발주 엑셀/CSV를 받아서 미트엘(제조업체) 발주서로 자동 변환하고 카카오톡으로 전송하는 PyQt6 데스크탑 앱

---

## 개발 환경

| 항목 | 내용 |
|------|------|
| OS | Windows 11 |
| Python | 3.11+ |
| GUI | PyQt6 |
| 주요 라이브러리 | pandas, openpyxl, olefile, cryptography, pyautogui, pywin32 |

설치:
```bash
pip install -r requirements.txt
```

실행:
```bash
python main.py
```

---

## 아키텍처

```
main.py         — PyQt6 GUI (메인 윈도우, 파일 선택, 미리보기 테이블)
processor.py    — 핵심 처리 로직 (복호화, 파싱, 변환, 엑셀 저장)
kakao.py        — 카카오톡 PC 앱 자동 전송 (pyautogui)
requirements.txt
```

### 처리 흐름

```
스마트스토어 XLSX (암호화 1111)
    └─ decrypt_smartstore()
       └─ parse_ss_option()
              ↓
           [발주 행들]
                ↓
카페24 CSV  ──→ parse_cafe24_row()  ──→ build_output()  ──→ save_output_excel()
```

## 사용 방법

1. 스마트스토어 셀러센터에서 **전체주문발주발송관리** XLSX 다운로드
2. 카페24 관리자에서 **주문 내보내기** CSV 다운로드
3. 앱 실행 → 파일 선택
4. **▶ 발주서 변환** 클릭
5. 미리보기 확인 → **💾 엑셀 저장**
6. **💬 카카오톡 전송** → 미트엘 채팅방으로 자동 발송
